# Michel Kahil — Portfolio

Personal portfolio website of **Michel Kahil**, graphic designer based in Montréal, QC.

## Live site

https://michel-kahil-portfolio.netlify.app

## Contents

- `index.html` — single-page portfolio (7 featured projects, about, contact)
- `styles.css` — all styling
- `images/` — project cover images

Projects link out to the full case studies on Behance: https://www.behance.net/michelkahil1

## Deploy

The site is a static build deployed on Netlify. Any push to `main` can be redeployed by uploading a fresh zip of the site root to the Netlify site `michel-kahil-portfolio`.
